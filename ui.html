Client tips

Windows Explorer: install the CA certificate below, then Map network drive → paste the https:// URL above.

macOS Finder: Go → Connect to Server (⌘K) → paste the URL.

Linux: davs:// / dav:// in Files, or rclone / davfs2.

iOS / Android: Files app, Documents, Solid Explorer, FolderSync, Joplin, Zotero, Obsidian, KeePass…

Encryption

Install it once on each device as a trusted root (Windows: “Trusted Root Certification Authorities”; macOS: Keychain → Always Trust; iOS: Settings → General → About → Certificate Trust Settings). Renewals are then trusted automatically.

App passwords

Give each device or app its own password. Revoke one without changing your main password. Optionally make it read-only or limit it to one folder.
